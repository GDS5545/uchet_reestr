ПЕРЕНОС СО СТАРОГО САЙТА В НОВЫЙ — ZAU 2.19.0

С версии 2.19.0 перенос выполняется одним инструментом на новом сайте —
никакой отдельный плагин на старом сайте больше не нужен.

Со старого сайта (Ultimate Member + форма заявления)
-----------------------------------------------------
1. Выгрузите пользователей Ultimate Member в CSV UTF-8 с колонкой ID
   пользователя (тот же ID, что стоит в конце имени файла личной карточки).
2. Выгрузите записи формы заявления в CSV UTF-8 с колонкой ID записи (тот же
   ID, что в конце имени файла PDF заявления) и колонкой ID пользователя —
   владельца заявления.
3. Скопируйте PDF заявлений и личных карточек — они понадобятся на шаге 3
   ниже.

На новом сайте
---------------
1. Откройте Профсоюз → Перенос со старого сайта.
2. Шаг 1 «Аккаунты»: загрузите CSV пользователей, сопоставьте колонку с ID
   пользователя Ultimate Member (обязательно), запустите «Только проверить»,
   затем настоящий перенос.
3. Шаг 2 «Заявления»: выберите форму нового кабинета для перенесённых
   заявлений, загрузите CSV заявлений, сопоставьте ID записи и ID
   пользователя-владельца (оба обязательны), запустите перенос.
4. Шаг 3 «Привязка PDF»: скопируйте PDF по FTP/SFTP в
   wp-content/uploads/zau-legacy-pdfs/, настройте, как распознавать личную
   карточку и заявление по имени файла и извлекать ID регулярным выражением,
   выберите PDF-шаблон для каждого типа, нажмите «Просканировать папку»,
   проверьте отчёт и нажмите «Привязать найденные PDF».

Надёжность
----------
Сопоставление везде идёт только по точным старым ID — без угадывания по
ФИО, email или телефону. Перенос безопасно запускать повторно: уже
перенесённые аккаунты, заявления и PDF не задваиваются, а обновляются на
месте. Исходные CSV и PDF-файлы не удаляются; успешно привязанные PDF
переносятся в подпапку «обработано».
