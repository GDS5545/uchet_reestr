ПЕРЕНОС СО СТАРОГО САЙТА В НОВЫЙ — ZAU 2.17.0

На старом сайте
---------------
1. Установите «ZAU — мост экспорта старого кабинета 1.1.0».
2. Откройте Инструменты → ZAU экспорт кабинета.
3. Включите защищённый API и сохраните настройки.
4. Скопируйте секретный ключ.

На новом сайте
--------------
1. Установите ZAU Профсоюз 2.17.0 поверх предыдущей версии.
2. Откройте Профсоюз → Перенос старого сайта.
3. Укажите адрес старого сайта и секретный ключ.
4. Оставьте безопасное правило «одно ФИО — на ручную проверку».
5. Выберите «в кабинете только самая новая заявка; старые сохранить в архиве».
6. Запустите полный пробный анализ.

Как читать отчёт
----------------
current            — самая новая уникальная заявка данного вида;
archived           — более старая уникальная запись, сохранённая в архиве;
exact_duplicate    — полное повторение более новой записи;
already_imported   — запись уже переносилась;
review_required    — недостаточно данных для безопасного объединения;
identity_conflict  — конфликт ИИН или совместно используемого email/телефона.

Настоящий перенос
-----------------
Запускайте только после проверки отчёта и резервной копии. Для каждого человека
создаётся один аккаунт. Профиль получает последние непустые сведения. В кабинет
по умолчанию попадает одна последняя заявка каждого вида.

PDF
---
Скопируйте PDF по FTP/SFTP в wp-content/uploads/legacy-user-pdfs/. После этого
запустите привязку PDF. Старые Entry ID архивных заявлений также сопоставляются
с актуальным пользователем.
