# ISMA Коммерция — шаблон для Elementor

Страница собрана из нативных элементов Elementor (контейнеры, Heading, Text Editor, Image, Button, Counter,
Icon List, Icon Box, Icon, Divider, Form), без HTML-виджета. Тексты, цвета, шрифты, отступы, радиусы, тени,
адаптив (desktop / tablet / mobile) и анимации появления заданы в настройках виджетов, поэтому всё правится в редакторе.

Файлы:
- `isma-ru.json` и `isma-kz.json` — шаблоны (RU и KZ-версия отдельными страницами).
- `isma-extra.css` — декоративный слой (уже встроен в шаблон как Custom CSS страницы).
- `images/` — логотип, 3 фото и 17 планировок (уже перекрашены в teal).
- `build_template.py` — генератор, чтобы пересобрать JSON под ваш адрес картинок.

## Установка

1. Загрузите всё из `images/` в Медиафайлы, например в `/wp-content/uploads/isma/`
   (можно положить по FTP в эту папку).
2. Пересоберите шаблон под ваш адрес:
   ```bash
   python3 build_template.py --base https://ВАШ-САЙТ/wp-content/uploads/isma/
   ```
   Для режима без Elementor Pro добавьте `--no-pro`. Номер WhatsApp меняется ключом `--wa 77718882020`.
3. WordPress → Elementor → Шаблоны → Импорт шаблонов → `isma-ru.json`. Elementor сам скачает картинки в медиатеку.
4. Создайте страницу, вставьте шаблон. Раскладка «Elementor на всю ширину» (Header & Footer или Canvas).
5. KZ-версию импортируйте так же и повесьте на `/kz/`. Кнопки RU/KZ в шапке ведут на `/` и `/kz/`, адреса можно поменять в кнопках.

## Что нужно для точного вида

- Elementor 3.27 или новее (Flexbox и Grid контейнеры) и Elementor Pro (виджет Form).
- В конце страницы лежит один служебный контейнер с HTML-виджетом `isma-service`. В нём только CSS (орнаменты, золотой
  градиент текста, кольца, 3D-стекло) и JS (калькулятор, фильтр, счётчики, появление при прокрутке). Его нельзя удалять.
  Вся вёрстка при этом остаётся нативными виджетами.

## Что работает, как в HTML

- Калькулятор: выбор помещения и скидка 10% (поля сделаны виджетами Form, скрипт считает и анимирует числа).
- Фильтр по улицам, «2 этаж» и сортировка планировок.
- Кнопка «Узнать о помещении» подставляет помещение в форму заявки, «Расчёт» — в калькулятор.
- Счётчики, анимации появления при прокрутке, телефонная маска, копирование номера.

## Отличия

- Переключение языка заменено двумя страницами RU/KZ (кнопки в шапке ведут на `/` и `/kz/`).
- Заявка уходит на e-mail администратора, Bitrix24 подключается в настройках виджета Form (Actions After Submit → Webhook).
- 3D-стекло упрощено до двух слоёв.
