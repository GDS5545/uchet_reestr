# ISMA Коммерция — шаблон для Elementor

Страница собрана из нативных элементов Elementor (контейнеры, Heading, Text Editor, Image, Button, Counter,
Icon List, Icon Box, Icon, Divider, Form), без HTML-виджета. Тексты, цвета, шрифты, отступы, радиусы, тени,
адаптив (desktop / tablet / mobile) и анимации появления заданы в настройках виджетов, поэтому всё правится в редакторе.

Файлы:
- `isma-ru.json` и `isma-kz.json` — шаблоны (RU и KZ-версия отдельными страницами).
- `isma-extra.css` — декоративный слой (уже встроен в шаблон как Custom CSS страницы).
- `images/` — логотип, 3 фото и 17 планировок (уже перекрашены в teal).
- `build_template.py` — генератор, чтобы пересобрать JSON под ваш адрес картинок.

## Установка

1. Загрузите всё из `images/` в Медиафайлы, например в `/wp-content/uploads/isma/`
   (можно положить по FTP в эту папку).
2. Пересоберите шаблон под ваш адрес:
   ```bash
   python3 build_template.py --base https://ВАШ-САЙТ/wp-content/uploads/isma/
   ```
   Для режима без Elementor Pro добавьте `--no-pro`. Номер WhatsApp меняется ключом `--wa 77718882020`.
3. WordPress → Elementor → Шаблоны → Импорт шаблонов → `isma-ru.json`. Elementor сам скачает картинки в медиатеку.
4. Создайте страницу, вставьте шаблон. Раскладка «Elementor на всю ширину» (Header & Footer или Canvas).
5. KZ-версию импортируйте так же и повесьте на `/kz/`. Кнопки RU/KZ в шапке ведут на `/` и `/kz/`, адреса можно поменять в кнопках.

## Что нужно для точного вида

- Elementor 3.27 или новее с включёнными Flexbox Container и Grid Container.
- Elementor Pro для Custom CSS страницы (орнаменты, золотой градиент текста, кольца, 3D-стекло, Ken Burns),
  для виджета Form и для Sticky.
  Без Pro всё, кроме декоративного слоя, работает. Тогда вставьте содержимое `isma-extra.css` в
  Внешний вид → Настроить → Дополнительный CSS, оно бесплатное.

## Отличия от HTML-версии

Это то, что в Elementor без JavaScript реализовать нельзя:

- Калькулятор: показан готовый расчёт для НП-1 (те же формулы, что в оригинале, числа анимируются Counter-виджетами). Выбор помещения и переключатель скидки не работают.
- Фильтр по улицам и сортировка планировок убраны: показаны все 17 карточек по порядку. Кнопка «Узнать о помещении» открывает WhatsApp с готовым текстом про это помещение.
- Форма: виджет Form (Pro), отправка на e-mail администратора. Bitrix24 подключается в настройках виджета (Actions After Submit → Webhook).
- Переключение языка заменено двумя страницами RU/KZ.
- Counter показывает десятичные через точку (14.4), а не через запятую.
- 3D-стекло на героe и у формы упрощено до двух слоёв, а не 12 срезов.
- Reveal-on-scroll заменён штатными анимациями входа Elementor (Fade In Up с задержками, как в оригинале).

Проверка шаблона на живом Elementor не выполнялась (в окружении нет WordPress), поэтому после импорта
пробегитесь по страницe глазами. Если какой-то блок отображается не так, пришлите скриншот.
