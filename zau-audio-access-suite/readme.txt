ZAU Аудиодоступ — объединённый доступ к аудиокнигам
====================================================

Версия: 1.2.0

Этот плагин объединяет функциональность восьми ранее раздельных плагинов
в один:

  1. wc-secure-audio-access          — постоянные ссылки, устройства, Passkey, OTP
  2. wcsaa-legacy-access-migrator    — перенос старых доступов
  3. wcsaa-zau-bridge                — мост между WCSAA и ZAU
  4. woo-amo-confirm-access          — интеграция amoCRM (OAuth, лиды, вебхук)
  5. woo-kaspi-payment-instructions-addon — страница инструкций Kaspi
  6. woo-kaspi-qr-amo-access         — шлюз оплаты Kaspi QR
  7. zau-audiobook-suite             — плеер, шифрование, CPT аудиофайлов
  8. zau-simple-permanent-access     — постоянный доступ через устройство

Зачем объединять
-----------------
Аудит исходных плагинов показал, что они реализуют ТРИ независимых системы
доступа, ДВА разных шлюза Kaspi и ДВЕ интеграции amoCRM, которые не знают
друг о друге и создают дублирующиеся e-mail, настройки и таблицы. Этот
плагин оставляет ровно одну реализацию каждого механизма:

  - Единая таблица грантов `wp_zaas_grants` вместо трёх разных хранилищ
    (wcsaa_grants, zau_audio_lock_temp_access, _wkqaa_book_access).
  - Единая модель устройств `wp_zaas_devices` + `wp_zaas_passkeys`
    (реальный WebAuthn) вместо трёх реализаций «запомнить браузер».
  - Единый email-OTP `wp_zaas_otp`, используемый и для восстановления
    ссылки входа, и для сброса PIN.
  - Один платёжный шлюз Kaspi (класс WC_Gateway_ZAAS_Kaspi), в который
    встроена страница-инструкция с QR и загрузкой чека — раньше это были
    два отдельных плагина.
  - Одна интеграция amoCRM (OAuth2, создание сделки, вебхук подтверждения)
    вместо двух конкурирующих реализаций.
  - Подтверждение оплаты (Kaspi вручную/по вебхуку ИЛИ amoCRM) всегда
    идёт через стандартный `$order->payment_complete()` / статус
    `completed`, на который уже подписано создание грантов — поэтому
    письмо с доступом отправляется из одного места, а не из пяти.

Аудио-виджет — это плеер И замок одновременно (v1.2.0)
---------------------------------------------------------
В исходных плагинах (в частности, у zau-audiobook-suite и его Elementor-
виджета) вставленный в страницу аудио-виджет сам был точкой входа: пока
посетитель не вошёл, вместо плеера показывалась форма входа, а не
предложение купить. Это поведение сохранено:

  - [zaas_audio], [zaas_protected] и Elementor-виджеты «Аудиоплеер» /
    «Защищённый блок» показывают форму входа (ZAAS_Access::auth_shortcode)
    незалогиненному посетителю прямо на месте плеера/контента.
  - «Купить» показывается только когда личность посетителя уже известна
    (есть устройство/сессия) и точно установлено, что этот конкретный
    товар им не куплен — а не просто потому, что он не вошёл.
  - Добавлен третий способ входа — обычный логин/email и пароль
    WordPress (`auth_password_enabled`, ZAAS Аудиодоступ → PIN и вход):
    работает через `wp_authenticate()` + `wp_set_auth_cookie()`, но
    открывает доступ только если у этого email есть активный грант —
    правильный пароль сам по себе доступа не даёт.
  - У виджетов «Вход», «Аудиоплеер» и «Защищённый блок» в Elementor
    появилась вкладка «Способы входа» — можно для конкретного места на
    сайте показать, например, только PIN, без email-ссылки и пароля
    (сузить, но не расширить то, что включено глобально).
  - `resolve_customer_email()` дополнительно распознаёт визитера, уже
    вошедшего в WordPress каким-то другим способом (wp-login.php), если
    его email владеет активным доступом — и тихо привязывает браузер как
    устройство, чтобы дальнейшие запросы шли уже по cookie.

Новое, чего не было ни в одном из исходных плагинов
----------------------------------------------------
  - Постоянный PIN-вход, оформленный по образцу плагина «ZAU Профсоюз»
    (ZAU_Union_Module): PIN хранится только хешем (wp_hash_password),
    вход и попытки ограничены transient-блокировкой, восстановление —
    через email-код, есть режим «PIN без email на привязанном
    устройстве».
  - Elementor: категория «ZAU Аудиодоступ» с виджетами Библиотека, Вход,
    Аудиоплеер, Защищённый блок, Кнопка покупки — у каждого есть вкладка
    «Стиль» с палитрой цветов, типографикой и радиусом, которая
    переопределяет CSS-переменные --zaas-e-* только для этого виджета.
  - Единая админ-панель управления настройками и стилями
    (ZAU Аудиодоступ → Стили): фирменный цвет, радиус скругления и т.д.
    применяются на фронтенде через CSS custom properties и один вызов
    JS (assets/js/theme.js) — без генерации CSS на сервере.

Что перенесено при импорте старых данных
-----------------------------------------
Экран «ZAU Аудиодоступ → Импорт» ищет и копирует в `wp_zaas_grants`:
  - активные строки старой таблицы `wp_wcsaa_grants`;
  - записи опции `zau_audio_lock_temp_access` (ядро ZAU / мост / ZSPA);
  - пользовательскую мету `_wkqaa_book_access` (Woo Kaspi QR amoCRM Access).

Импорт идемпотентен: повторный запуск не создаёт дублей (уникальный ключ
по order_id+order_item_id+product_id+email).

Прочие функции исходных плагинов, перенесённые в этот релиз
--------------------------------------------------------------
  - Ручная выдача доступа одному email без заказа (ZAU Аудиодоступ →
    Гранты → «Выдать доступ вручную») — аналог формы
    wcsaa-legacy-access-migrator.
  - Статус сделки amoCRM и кнопки «Отправить в amoCRM» / «Подтвердить
    доступ вручную», статус Kaspi и кнопки «Подтвердить оплату» /
    «Отклонить» — прямо в карточке заказа WooCommerce (парity с WAOA и
    WKQAA).
  - Гранулярные шорткоды метаданных книги: [zaas_audio_cover],
    [zaas_audio_title], [zaas_audio_author], [zaas_audio_part],
    [zaas_audio_badge], [zaas_audio_bundle product_id="45"] — для страниц
    с собственной вёрсткой карточки книги (аналог
    zau_audio_cover/title/author/part/badge/bundle).
  - Алиасы шорткодов Kaspi для сайтов, где на страницах уже есть
    [kaspi_protected_content], [kaspi_buy_button], [kaspi_receipt_upload]
    из старого Woo Kaspi QR amoCRM Access — работают без правок разметки.
  - Вкладка «Мои книги» в WooCommerce → Моя учётная запись (аналог My
    Books из WKQAA).
  - «Проверка» (ZAU Аудиодоступ → Проверка) — диагностика защищённой
    папки, таблиц БД, HTTPS/OpenSSL для Passkey, статуса amoCRM/Kaspi,
    правил ЧПУ и крона — аналог «Проверка Suite» из zau-audiobook-suite.
  - Докачиваемая загрузка больших файлов частями по 5 МБ прямо в
    браузере, с шифрованием каждой части на лету (ZAU Аудиодоступ →
    Файлы) — аналог class-zau-suite-replace.php, без необходимости менять
    upload_max_filesize на сервере.
  - Опциональный PWA-режим (по умолчанию выключен, включается в
    ZAU Аудиодоступ → Стили): манифест, service worker и кнопка
    «Установить» на странице библиотеки — аналог Suite PWA, но никогда
    не кэширует /zaas-stream/, /wp-admin/, /wp-json/ и admin-ajax.php.
  - Ежедневная очистка просроченных грантов и старых отозванных устройств
    по крону — аналог wcsaa_daily_cleanup.

Не перенесено (сделайте это до отключения старых плагинов)
------------------------------------------------------------
  - Устройства/Passkey старых плагинов — клиенты просто заново привязывают
    устройство при первом входе в новую систему (ссылка или PIN).
  - Бесподписные ECDSA/IndexedDB-ключи ZSPA — заменены на настоящий
    WebAuthn (ZAAS_WebAuthn), несовместимы напрямую.
  - Формат ZAURPL01 (Sodium/XChaCha20, инструмент «ZAU Audio Replace
    Editor 1.0.0») — восстанавливайте оригинальным инструментом
    zau-audiobook-suite ДО перехода: этот плагин не умеет читать этот
    контейнер, а без прежних значений AUTH_KEY/AUTH_SALT восстановление
    невозможно в принципе.

Порядок перехода
-----------------
1. Установите и активируйте этот плагин на копии сайта.
2. ZAU Аудиодоступ → Файлы: загрузите mp3/m4a — они будут зашифрованы
   заново (XOR, ключ из wp_salt) в защищённой папке
   wp-content/uploads/zaas-protected-audio/.
3. ZAU Аудиодоступ → Импорт: запустите перенос по каждому найденному
   источнику, проверьте счётчики.
4. Проверьте вход по постоянной ссылке, по PIN и (если есть HTTPS) по
   Passkey на нескольких тестовых аккаунтах.
5. Настройте WooCommerce → Способы оплаты → Kaspi QR (шаблон ссылки, QR,
   секрет вебхука) и, если нужно, ZAU Аудиодоступ → amoCRM.
6. Только после проверки отключите старые 8 плагинов.

Nginx
-----
Как и в исходных плагинах, `.htaccess` внутри защищённой папки не
действует на Nginx — добавьте вручную:

    location ^~ /wp-content/uploads/zaas-protected-audio/ {
        deny all;
    }

Кэш
---
Исключите из кэширования: страницу библиотеки (`[zaas_library]`),
`/audio-dostup/*`, `/moya-kniga/*`, `/zaas-stream/*`, а также ajax-действия
`zaas_*` и `wp-json/zaas/v1/*`.

Шорткоды
--------
  [zaas_library]                          — кабинет / список книг
  [zaas_auth methods="recovery,pin,password"] — форма входа (ссылка на email / PIN / логин и пароль; methods необязателен)
  [zaas_audio id="123"]                   — плеер + замок: без входа показывает форму входа вместо плеера
  [zaas_protected product_id="45"]...[/zaas_protected] — блок только для владельцев
  [zaas_buy_button product_id="45"]       — кнопка покупки
  [zaas_audio_cover id="123"]             — обложка файла
  [zaas_audio_title id="123"]             — название файла
  [zaas_audio_author id="123"]            — автор/чтец
  [zaas_audio_part id="123"]              — часть/глава
  [zaas_audio_badge id="123"]             — бейдж «Доступно» / «Нет доступа»
  [zaas_audio_bundle product_id="45"]     — все части книги списком с плеером
  [kaspi_protected_content] / [kaspi_buy_button] / [kaspi_receipt_upload] — алиасы для миграции с Woo Kaspi QR amoCRM Access
