ZAU Профсоюз 2.8.2 — исправление кнопки регистрации

Исправлено:
1. Кнопки «Впервые здесь» и «У меня есть кабинет» снова переключают нужные экраны.
2. Регистрационный экран теперь отображается сервером сразу, даже если JavaScript задержан плагином кэширования или оптимизации.
3. После нажатия «Впервые здесь» открывается ввод email/телефона для получения кода регистрации.
4. Добавлена повторная инициализация виджета при динамической загрузке Elementor.
5. Исправлено кэширование: версии CSS и JavaScript теперь включают время изменения файла, поэтому браузер не использует старый union-public.js после обновления.
6. Версия внутреннего модуля синхронизирована с версией основного плагина.

После обновления:
- очистите кэш сайта/CDN;
- в Elementor → Инструменты нажмите «Пересоздать CSS и данные»;
- обновите страницу регистрации с жёсткой перезагрузкой браузера.
