ZAU Профсоюз 2.14.3 — регистрация сразу через анкету

1. Новый режим регистрации по умолчанию: без отправки и проверки одноразового кода.
2. Незарегистрированный участник сразу видит полную форму регистрации.
3. После отправки анкеты WordPress-аккаунт создаётся автоматически, пользователь автоматически входит в личный кабинет.
4. Email/телефон проверяются на дубли: существующий аккаунт нельзя перехватить прямой регистрацией.
5. Добавлены защита от ботов: скрытое поле, контроль времени заполнения и ограничение количества регистраций с одного IP.
6. PIN можно создать прямо в регистрационной форме согласно существующей настройке «Создание PIN при регистрации».
7. Одноразовый код остаётся доступен для входа и восстановления, но не показывается на этапе регистрации.
8. В настройках можно временно вернуть старый сценарий регистрации с подтверждением кода.

После обновления:
Профсоюз → Вход, PIN и API → Регистрация новых участников → выберите «Сразу показывать форму — без подтверждающего кода».
Очистите LiteSpeed Cache и кэш браузера.
