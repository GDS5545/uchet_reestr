ОБНОВЛЕНИЕ ДО 2.6.0

1. Сделайте резервную копию базы данных и wp-content/uploads.
2. Установите ZIP поверх предыдущей версии и подтвердите замену.
3. При обновлении существующие пользователи, заявки, PDF, подписи, QR и вручную настроенные координаты шаблонов не перезаписываются.

НОВОЕ

— В реестре документов появилась кнопка «Пересоздать PDF».
  Она сохраняет владельца, ID строки, номер документа и QR-токен, а старый файл заменяется только после успешной генерации нового.
— Действие «Удалить файлы» удаляет только PDF/JPG, оставляя запись и данные для повторной генерации.
— Номер нового документа теперь формируется по фактическому автоинкрементному ID строки базы. Это исключает одинаковые номера при одновременных отправках.
— Филиалы можно массово вставлять простым списком через запятую или подробными строками через точку с запятой/табуляцию.
— Создаётся отдельная страница /reestr-organizacii/ с шорткодом [zau_union_org_registry].
— Ответственный организации видит только назначенные ему организации.
— В реестре доступны фильтры по ФИО, дате регистрации, организации, телефону, email и типу документа.
— Можно выбрать отдельные строки либо выгрузить все отфильтрованные строки.
— Добавлены экспорт Excel, экспорт PDF и скачивание PDF-документов выбранных участников в ZIP.
— Для каждого документа есть защищённые кнопки «Просмотр» и «Скачать».
— В Elementor-виджет «ZAU — раздел кабинета» добавлен вариант «Реестр организации с экспортом».

ЗАВИСИМОСТЬ ZIP

Для массового скачивания документов ZIP на сервере должно быть включено PHP-расширение ZipArchive. Отдельное скачивание PDF работает независимо от ZipArchive.
