ZAU Профсоюз 2.21.0 — только последние заявления в кабинете и реестре

Раньше, если участник подавал одну и ту же форму несколько раз (либо
несколько записей пришло с переноса со старого сайта), в личном кабинете
и в реестре организации показывались ВСЕ поданные версии — старые и
новые вперемешку.

Теперь показывается только самая свежая версия по каждой форме/шаблону:
- Личный кабинет, вкладка «Заявления» — одна строка на форму (самая
  новая по дате).
- Личный кабинет, вкладка «Документы» — один документ на шаблон
  (самый свежий).
- Личный кабинет, «Главная» — счётчики «Документов»/«Заявлений»
  тоже считают только различные формы/шаблоны, а не все записи.
- «Участники моей организации» (для ответственных) — те же счётчики.
- Реестр организации (страница, Excel, PDF, ZIP-выгрузка) — в колонке
  «Документы» на человека только последний документ каждого вида.

Административная страница «Заявки участников» (Профсоюз → Заявки
участников) не изменена — там по-прежнему видна полная история всех
поданных версий, это инструмент для проверки и аудита.

Старые версии заявлений и документов никуда не удаляются — они просто
не показываются в перечисленных местах, пока остаются не самыми свежими
по своей форме/шаблону.
