ZAU Профсоюз 2.33.0 — черновики и контроль документов перенесённых

«Черновик» в реестре = запись и номер документа созданы, но PDF ещё не
нарисован (очередь не запускали, закрыли вкладку, была ошибка). Данные
заявления и подпись в записи уже есть — нужно только дорисовать PDF.

Реестр документов:
- фильтры: «Из перенесённых заявлений старого сайта» / «Остальные»;
  статус (Черновик / Действителен / Отозван); PDF есть / нет;
- постраничный просмотр по 100 (раньше показывались только последние 500);
- у документов из перенесённых заявлений пометка «со старого сайта ·
  заявление от …» — ссылка ведёт в карточку сверки участника;
- кнопка «Сформировать PDF для найденных черновиков» — ставит все найденные
  документы без PDF в очередь «Массового пересоздания»;
- у черновика кнопка называется «Сформировать PDF».

Пересоздание и активация — блок «Итог»:
- сколько перенесённых участников: все документы готовы / есть черновики /
  документов нет;
- «Дорисовать PDF для всех черновиков»;
- «Скачать CSV по участникам» (заявления, готовые документы, черновики,
  номера, статус, дата вступления, активирован ли);
- «Открыть в реестре».

Технически: документы из перенесённых заявлений записываются в отдельный
индекс (таблица zau_exact_docs), уже созданные подхватываются при обновлении.
