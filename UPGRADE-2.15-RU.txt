ZAU Профсоюз 2.15.0 — универсальный перенос аккаунтов и заявлений

Добавлено:
- раздел «Профсоюз → Импорт аккаунтов»;
- загрузка CSV/TXT до 50 МБ;
- определение разделителя и Windows-1251/UTF-8;
- визуальное сопоставление колонок старого файла с новой системой;
- режимы: аккаунты + заявления, только аккаунты, только заявления;
- поиск дублей по ИИН, email, телефону и старому User ID;
- создание новых WordPress-аккаунтов без отправки писем;
- дополнение существующих профилей без перезаписи заполненных данных по умолчанию;
- перенос личных данных в профиль и личную карточку;
- автоматическое сопоставление филиала по названию/региону;
- создание организаций по БИН при наличии названия;
- архивная форма «Архивные заявления со старого сайта»;
- сохранение всех исходных колонок в legacy_fields;
- тестовый режим без записи;
- пакетная обработка и CSV-отчёт;
- защита от повторного импорта одной строки.

Важно:
1. Перед переносом создайте резервную копию базы данных.
2. Первый запуск выполните в режиме «Только проверить».
3. Затем импортируйте 10–20 тестовых строк и проверьте кабинеты.
4. Пароли в версии 2.15.0 не переносятся. Пользователь входит по коду или восстанавливает PIN.
5. Старые PDF пока сохраняются в данных заявления как legacy_pdf_url. Регистрацию файлов в реестре следует настраивать после получения примера старого экспорта/структуры файлов.
