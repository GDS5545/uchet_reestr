ZAU Профсоюз 2.24.13 — восстановление полей у уже загруженных заявок

Для заявок, которые попали в базу напрямую (не через сопоставление
колонок этого плагина), данные могли сохраниться под «сырыми»
названиями старых полей — например «от Ф.И.О.» вместо full_name,
«Наименование организации» вместо organization, «Ф.И.О. руководителя»
вместо organization_director, «Филиал» вместо branch_name. Из-за этого
поля не подставлялись в PDF, участник не появлялся в реестре
организации, а при пересоздании документа могло остаться старое,
ошибочно записанное туда ФИО другого человека.

Новый блок «Профсоюз → Перенос со старого сайта → Восстановление полей
у уже загруженных заявок»:

1. Выберите форму (например «Архивные заявления со старого сайта») и
   нажмите «Проверить форму» — плагин просмотрит до 300 последних
   заявок этой формы и покажет все поля, которые не распознаются как
   стандартные (ФИО, организация, руководитель, филиал и т.д.), с
   примерами значений и количеством заявок, где встречается поле.
2. Для каждого найденного поля выберите, с каким стандартным полем его
   сопоставить.
3. Отметьте «Обновить ФИО и организацию в уже созданных документах»,
   если нужно сразу исправить и записи уже сформированных документов
   (не только заявку) — например когда там по ошибке оказалось ФИО
   другого участника.
4. Сначала нажмите «Только проверить» — покажет, сколько заявок и
   документов будет затронуто, без записи в базу. Затем «Исправить
   данные» — применит по-настоящему, порциями, с прогрессом.
5. Список изменённых документов (было ФИО/организация → стало)
   можно скачать CSV-отчётом — на случай, если нужно перепроверить.

Важно: сама заявка и запись документа в базе обновляются сразу, а вот
готовый файл PDF — нет. Чтобы исправленные данные попали в сам файл,
после восстановления полей запустите «Профсоюз → Массовое пересоздание»
для этой же формы/шаблонов.

Инструмент ничего не удаляет и не трогает поля, которые уже заполнены
(если не включена галочка «Перезаписывать») — только дозаполняет
пустые. ID сопоставления заявок со старым сайтом (для повторного
переноса) не переопределяются.
