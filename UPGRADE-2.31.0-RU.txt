ZAU Профсоюз 2.31.0 — пересоздание перенесённых заявлений по новым шаблонам

Новая вкладка: «Импорт и перенос → Пересоздание по новым шаблонам».

Что делает: для каждого заявления, перенесённого со старого сайта и закреплённого
за своим владельцем (статус «своё»), создаёт документ по PDF-шаблонам выбранной
новой формы:
- поля заполняются из старого заявления (ФИО, ИИН, организация, руководитель,
  филиал и т.д.); профиль участника дополняет только то, чего в заявлении не было;
- подпись — из старого заявления (файл, скопированный на новый сайт);
- дата документа и дата создания записи — дата старого заявления;
- номер документа выдаётся по текущей нумерации шаблона;
- документ появляется в личном кабинете участника и в реестре.

Не затрагивает: заявления, поданные на новом сайте, и их документы; чужие,
спорные, неразобранные и скрытые записи старого сайта; сами перенесённые
заявления (архив остаётся); PDF, привязанные прежними переносами.

Порядок:
1. Для каждой формы старого сайта выберите новую форму (её PDF-шаблоны) и
   сохраните. «Пропускать без подписи» — включено по умолчанию.
2. Укажите ID 1–3 участников, «Подготовить документы», затем «Открыть очередь
   и сформировать PDF» → «Продолжить». Проверьте документы.
3. Очистите поле ID и запустите для всех. Очередь можно ставить на паузу и
   продолжать позже; ошибки видны в CSV очереди.
Повторный запуск не создаёт дублей: готовые документы пропускаются. Галочка
«Пересоздать и те…» перерисовывает их (номер сохраняется, файл заменяется).
Отмена: «Удалить документы, созданные этим инструментом» — удаляет только их.

В карточке «Подробнее» на странице проверки ФИО есть кнопка пересоздания
для одного участника. В «Массовом пересоздании» добавлен фильтр
«Пересозданные из заявлений старого сайта».
