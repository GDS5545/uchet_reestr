ZAU Профсоюз 2.11.0 — массовое пересоздание PDF
=================================================

Добавлен раздел:
Профсоюз → Массовое пересоздание

Возможности:
- фильтрация по ФИО, номеру, организации, шаблону, статусу, дате и источнику;
- работа со всем найденным списком либо с указанными ID и диапазонами;
- назначение нового шаблона старым импортированным PDF;
- применение актуального префикса и формата номера;
- сохранение старых PDF/JPG в истории до успешной проверки нового файла;
- пропуск записей без подписи;
- постоянная очередь, которую можно поставить на паузу и продолжить после перезагрузки;
- автоматические повторы при временных ошибках;
- CSV-отчёт по каждому документу.

Безопасный порядок запуска:
1. Сделайте резервную копию базы и wp-content/uploads.
2. Проверьте новый шаблон на 1–3 документах через обычную кнопку «Пересоздать PDF».
3. Откройте массовое пересоздание и нажмите «Проверить выборку».
4. Для первого массового теста установите максимум 10–20 документов.
5. После проверки увеличьте выборку.
6. Не закрывайте вкладку во время активной обработки. Если закрыли — очередь сохранится, её можно продолжить позже.

Важно:
- QR-токен и ID документа сохраняются;
- новый файл заменяет ссылку в реестре только после успешной генерации;
- при включённой опции старый файл не удаляется и записывается в _zau_file_history;
- для старых PDF без template_id необходимо выбрать целевой шаблон;
- массовое формирование выполняется последовательно в браузере, чтобы не создавать сотни одновременных PHP-процессов.
