ZAU Профсоюз 2.18.5 — только последний документ по каждому виду в кабинете

1. Вкладка «Мои документы» личного кабинета (обычный кабинет, блочный
   конструктор, Elementor-виджет и кнопка «Обновить документы») теперь
   показывает только самый свежий документ по каждому виду — заявление о
   вступлении, заявление на уплату взносов, личная карточка и т.д. Раньше
   при каждой пересдаче заявления в кабинете накапливались все старые
   документы, из-за чего один и тот же вид документа мог показываться по
   несколько раз с разными номерами.
2. Документ определяется как «того же вида», если у него совпадает шаблон
   PDF; для документов, перенесённых со старого сайта без привязки к
   шаблону, вид определяется по названию документа.
3. Счётчик «Документов» в статистике кабинета считает так же — только по
   последнему документу каждого вида.
4. Кнопка «Сформировать PDF» во вкладке «Мои заявления» по-прежнему видит
   все документы всех заявлений (а не только последние), чтобы не
   предлагать повторно формировать уже готовый PDF.
5. Ничего не удаляется: старые документы остаются в базе данных и в
   админском разделе «Профсоюз → Заявки участников» / реестре организации
   для истории. Скрывается только их отображение в личном кабинете
   участника.

Обновление не меняет структуру базы данных.
