Версия 2.11.0


НОВОЕ В 2.11.0 — МАССОВОЕ ПЕРЕСОЗДАНИЕ PDF
================================================

В меню «Профсоюз» добавлен раздел «Массовое пересоздание». Он позволяет безопасно пересобрать документы по фильтрам, назначить новый шаблон перенесённым PDF, обновить префиксы и номера, сохранить прежние файлы в архиве и получить CSV-отчёт. Очередь хранится в базе и может быть продолжена после перезагрузки страницы.

НОВОЕ В 2.10.0 — ПЕРЕНОС СТАРЫХ ДАННЫХ
- Добавлен мастер «Профсоюз → Перенос старых данных».
- Перенос существующих записей WPForms в новые заявки небольшими AJAX-партиями.
- Автоматическое сопоставление пользователей по старому user_id, email и телефону.
- Сохранение прежних ID пользователей при установке на существующий сайт или при полном клонировании базы.
- Перенос ФИО, телефона, региона, организации, БИН, руководителя, филиала, должности и подписей в новый профиль.

- После переноса старые заявки появляются во вкладке «Заявления», а PDF — во вкладке «Документы» и в реестре ответственного.

БЕЗОПАСНЫЙ ПОРЯДОК ПЕРЕНОСА
1. Скопируйте базу данных и всю папку wp-content/uploads.
2. Не удаляйте WPForms, WPForms Signatures, Ultimate Member и User PDF Shortcodes до завершения проверки.
3. Установите версию 2.10.0 на тот же сайт либо на полную копию сайта.
4. Откройте «Профсоюз → Перенос старых данных».
5. Сначала запустите «Только анализ».
6. Проверьте количество найденных форм, заявок и PDF.
7. Запустите перенос и дождитесь 100%.
8. Проверьте несколько старых пользователей, их заявления, подписи и PDF.
9. Только после контрольной проверки можно отключать старые шорткоды и старые страницы кабинета.

ПЕРВИЧНАЯ НАСТРОЙКА
После активации появится меню «Профсоюз».

1. ПРОФСОЮЗ → ВХОД ПО КОДУ И API
- Проверьте автоматически созданные страницы.
- Email-коды отправляются через wp_mail. На рабочем сайте должен быть исправно настроен SMTP.
- Для кодов по телефону укажите SMS webhook URL.
- Плагин отправляет POST JSON:
  {"phone":"+77000000000","code":"123456","message":"Код входа..."}
- Пользовательские аккаунты входят по коду. Административные аккаунты WordPress оставлены на стандартном входе ради безопасности.

2. ПРОФСОЮЗ → ВХОД ПО КОДУ И API → DADATA
- Получите API-ключ в аккаунте DaData и вставьте его в настройках.
- Включите «Использовать DaData» и при необходимости подсказки во время ввода.
- Ключ не передаётся браузеру: WordPress выполняет запросы к party_kz со своего сервера.
- По частичному БИН показывается список организаций, по полному 12-значному БИН выполняется точный поиск.
- Автоматически доступны: БИН, названия RU/KZ, руководитель, адреса RU/KZ, статус, тип, дата регистрации, ОКЭД и КАТО.
- Результаты кэшируются и сохраняются во внутренний справочник.

3. ПРОФСОЮЗ → ОРГАНИЗАЦИИ И БИН
- Можно добавлять организации вручную.
- Можно импортировать CSV с колонками:
  БИН;Наименование;Руководитель;Адрес;Регион
- Внутренний справочник служит резервом при временной недоступности внешнего API.
- Универсальный API с URL {bin} сохранён как дополнительный резервный источник.
- Сам плагин не содержит чужой API-ключ.

4. ПРОФСОЮЗ → ШАБЛОНЫ
Создайте отдельные шаблоны:
- заявление на вступление;
- заявление на удержание/уплату взносов;
- сертификат участника;
- любые другие документы.

Для каждого шаблона:
- выберите книжную либо альбомную ориентацию;
- загрузите JPG/PNG-подложку;
- включите необходимые поля;
- перетащите поля на нужные места;
- включите «Подпись» и QR;
- сохраните шаблон.

После сохранения формы её собственные поля появляются в редакторе шаблонов. Например:
- organization_bin;
- organization_director;
- organization_address;
- first_name;
- last_name;
- phone;
- signature.

5. ПРОФСОЮЗ → ФОРМЫ РЕГИСТРАЦИИ
В конструкторе доступны типы:
- текст;
- email;
- телефон;
- число;
- дата;
- многострочный текст;
- выпадающий список;
- выбор филиала с автоматической подстановкой реквизитов;
- флажок согласия;
- поиск по БИН;
- рисуемая подпись;
- заголовок раздела;
- скрытое поле.

К форме можно привязать сразу несколько PDF-шаблонов. После одной отправки будут сформированы все выбранные документы.

ШОРТКОДЫ
[zau_union_auth]
Вход/регистрация по коду.

[zau_union_form]
Форма по умолчанию.

[zau_union_form id="1"]
Конкретная форма.

[zau_union_portal]
Если пользователь не вошёл — показывает вход по коду; после входа — форму.

[zau_union_cabinet]
Личный кабинет, заявления, PDF и материалы для ознакомления.

[zau_certificate_verify]
Публичная проверка действительности записи. PDF и изображение документа не показываются и не выдаются на скачивание.

[zau_my_certificates]
Компактный список документов пользователя с защищённым просмотром.

[zau_union_org_members]
Список участников назначенной организации. Для ответственных автоматически выводится и внутри [zau_union_cabinet].

КАК РАБОТАЕТ ПОДПИСЬ
- Пользователь рисует подпись на Canvas.
- Подпись сохраняется отдельным PNG с прозрачным фоном в uploads/zau-signatures/YYYY/MM.
- Ссылка записывается в заявку и профиль документа.
- При генерации PNG накладывается на указанное место шаблона.
- Готовый PDF содержит визуально встроенную подпись.

СТАРЫЕ ПОДПИСИ И ДОКУМЕНТЫ
- Подписи, уже встроенные в старые PDF/JPG, остаются внутри файлов.
- Отдельные старые PNG WPForms Signatures не удаляются.
- Новый плагин не переписывает старые PDF.
- Автоматический перенос полей из конкретной старой формы WPForms требует карты ID полей этой формы. До выполнения такой миграции старые шорткоды нужно оставить активными.

СТАТУС ЧЛЕНСТВА
В профиле пользователя WordPress есть блок «Профсоюз» и поле статуса:
- Регистрация не завершена;
- Заявление подано;
- На рассмотрении;
- Состоит в профсоюзе;
- Членство приостановлено;
- Выбыл из профсоюза;
- Заявление отклонено.

QR-проверка показывает актуальный статус пользователя, если документ связан с его WordPress-аккаунтом.

ИНФОРМАЦИЯ В ЛИЧНОМ КАБИНЕТЕ
Добавляйте записи в разделе «Материалы для кабинета». Опубликованные материалы автоматически показываются участникам в [zau_union_cabinet].

ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
- WordPress 6.0+
- PHP 7.4+
- HTTPS для безопасной авторизации и рисования подписи
- рабочий wp_mail/SMTP для email-кодов

- фон шаблона желательно хранить в медиабиблиотеке того же сайта

ВАЖНО
Подтверждение одноразовым кодом и нарисованная подпись являются способом фиксации волеизъявления в системе, но не должны автоматически называться ЭЦП Республики Казахстан. Для юридически значимой ЭЦП требуется отдельная интеграция с НУЦ РК/NCALayer или другим допустимым механизмом.

ВЫБОР ДАННЫХ ДЛЯ ШАБЛОНА
В разделе «Профсоюз → Шаблоны» слева появляются все обнаруженные поля.
- Поле без префикса, например organization, использует значение заявки и при отсутствии — значение профиля.
- [Заявка] organization — точное значение, сохранённое при отправке формы.
- [Профиль] organization — актуальное значение в профиле пользователя, даже если оно добавлено после регистрации.
Таким образом один шаблон можно собирать из любых полей формы, DaData, профиля и ранее сохранённых заявок.

ПРОВЕРКА ПО QR
- Страница проверки открывается без входа по коду.
- Показывается только результат проверки записи, ФИО, тип, номер и дата документа, а также организация/статус, если администратор разрешил эти поля.
- PDF, JPG, прямая ссылка uploads, кнопка скачивания и встроенный просмотр документа на странице QR отсутствуют.
- Владелец открывает документ только из своего личного кабинета через защищённый обработчик WordPress.

ОТВЕТСТВЕННЫЕ ОРГАНИЗАЦИЙ
1. Откройте «Профсоюз → Участники и доступ».
2. Выберите организацию пользователя.
3. Включите «Управляет участниками выбранной организации».
4. После входа по коду в его личном кабинете появится раздел «Участники моей организации».
Ответственный не получает доступ к людям других организаций и не может удалять документы или менять настройки плагина.


ФИЛИАЛЫ И АВТОПОДСТАНОВКА РЕКВИЗИТОВ
1. Откройте «Профсоюз → Филиалы и реквизиты».
2. Добавьте название, регион, БИН, ИИК, БИК, банк, адрес, председателя, бухгалтера и контакты.
3. В форме выберите тип поля «Выбор филиала с автоподстановкой реквизитов» и используйте ключ branch.
4. После выбора филиала пользователь увидит карточку реквизитов, а в заявку автоматически попадут поля:
- branch_name
- branch_region
- branch_union_bin
- branch_iban
- branch_bik

Формат передачи данных исправлен, плюс добавлена общая защита от показа сломанного текста в будущем. Настройки «Навигация на телефоне» расширены: z-index (на случай перекрытия футером), промежутки, отступы, скругление, граница, размер подписи, фон активного пункта; сама панель теперь надёжнее держит закреплённое положение.
