ZAU Профсоюз 2.16.0 — перенос со старого сайта через защищённый мост

В комплекте с этой версией используется отдельный плагин для старого сайта:
ZAU — мост экспорта старого кабинета.

На новом сайте появился раздел:
Профсоюз → Перенос старого сайта

Возможности:
- защищённое подключение к старому WordPress по HMAC-подписи;
- пробный анализ без записи в базу;
- пакетный перенос аккаунтов;
- перенос личных данных из usermeta и Ultimate Member;
- перенос заявлений WPForms;
- поиск дублей по ИИН, email, телефону и старому user_id;
- сохранение всех исходных полей в legacy_fields;
- необязательное сохранение совместимых хешей старых WordPress-паролей только для новых аккаунтов;
- отдельная привязка PDF после копирования по FTP/SFTP;
- отчёты CSV по аккаунтам, заявлениям и PDF.

Безопасный порядок:
1. Сделать резервные копии обоих сайтов.
2. Установить экспортёр на старом сайте.
3. Включить API и скопировать секретный ключ.
4. На новом сайте сохранить адрес и ключ.
5. Проверить подключение.
6. Запустить пробный анализ.
7. Проверить отчёт и выполнить настоящий перенос.
8. Скопировать PDF в wp-content/uploads/legacy-user-pdfs/.
9. Запустить поиск и привязку PDF.
10. После проверки отключить API старого сайта.
