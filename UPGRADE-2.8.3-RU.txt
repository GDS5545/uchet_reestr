ZAU Профсоюз 2.8.3 — вход только по PIN

После регистрации и создания PIN текущее устройство автоматически привязывается к аккаунту. На этом устройстве при следующем входе показывается только поле PIN — email, телефон и логин вводить не нужно.

На новом устройстве требуется один раз войти одноразовым кодом или паролем. После этого устройство привязывается и дальнейший вход выполняется только по PIN.

Привязка использует случайный 256-битный токен в защищённой HttpOnly cookie. PIN хранится только как хеш. При восстановлении или административном сбросе PIN старые привязки устройств аннулируются.

Настройки: Профсоюз → Вход, PIN и API → Вход только по PIN / Срок привязки устройства.
